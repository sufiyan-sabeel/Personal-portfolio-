# Vault Portfolio - Umaiz Sufiyan

This is the source code for my personal portfolio website, designed as a cinematic showcase of my projects, skills, and experience as a Student Developer and AI Builder.

## Tech Stack

- **Framework**: React (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Motion
- **Icons**: Lucide React

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
